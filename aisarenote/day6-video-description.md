# オファー記事：商品説明（動画内容）セクション編集用データ

## このファイルの目的

オファー記事の「商品説明」セクションを編集するための元データ。
Claude Code はこのファイルを読み込み、記事内の該当セクションを作成・編集すること。

## 動画全体のタイトル

```
「私ばかり追う恋」を終わらせる
彼から愛される完全解説動画
```

## 表示ルール（重要）

各パートは次の4要素で構成する。

| 要素 | 内容 | 表示方法 |
|---|---|---|
| ① 番号ヘッダー | `01`〜`08` と、`｜` の後ろの見出し文 | **見出しではなく**、説明用ヘッダーとして**小さく**表示する |
| ② タイトル | 番号ヘッダーの次の行（2行目） | **最も大きく**目立たせる（このパートの主役） |
| ③ 画像 | 各パートに対応する画像 | タイトルの下に配置 |
| ④ 箇条書き | 3項目 | **画像の下**に表示する |

### 表示順（上から）

1. 番号ヘッダー（小・補助的な見た目）
2. タイトル（最大・強調）
3. 画像
4. 箇条書き（3項目）

### 実装上の注意

- 番号ヘッダー（例：`01｜彼の気持ちが分かる方法`）は `<h1>`〜`<h6>` などの見出しタグ・見出し記法（`#`）を**使わない**。小さいテキスト（例：`<p class="part-label">`）として扱う。
- タイトルは視覚的に最大サイズ。記事全体の見出し階層と矛盾しないよう、スタイルで大きさを出す。
- 動画全体のタイトルは、8パートの前に配置する。
- 文言は下記の原文のまま使用し、勝手に書き換えない（`〇〇` も原文のまま残す）。
